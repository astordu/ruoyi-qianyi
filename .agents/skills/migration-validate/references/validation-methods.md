# 按内容选择验证

先确定旧实现的可观察契约，再实现目标，重放相同条件。断言不要只检查新函数被调用、变量名称或 DOM 与新代码一致。

| 内容 | 本组检查 | 后续集成 |
| --- | --- | --- |
| 纯工具 | 同输入比较原/新输出和异常，含空值、边界、类型；纯 JS 可兼容复用。需要测试时沿用现有 Node test/Vitest | 实际调用契约变化时检查 |
| API/请求 | 方法、URL、编码、响应/错误、超时/取消、Token、副作用和请求次数；固定响应 | 必要真实后端互通、页面反馈；加密不能仅两边各自自测 |
| 状态/Hook | 动作→状态、身份切换、乱序、资源清理、重复挂载 | 权限和刷新恢复 |
| 公共组件 | 独立挂载，固定 props/数据，通过交互查展示、回调、受控更新、禁用/取消/空态；Vue Test Utils、React Testing Library 或现有测试挂载页 | 页面传参、事件处理、路由接线 |
| 页面 | 同角色/数据重放操作，断言页面、请求、Cookie/Storage；可用 Playwright | 跨页导航、权限、刷新和公共回归 |
| 样式/资源 | 引用映射、格式、真实加载、使用处截图并实际查看 | 布局、主题、小屏幕和交互状态 |
| 配置/注册 | 真实命令、入口/产物、别名、环境配置、动态注册 | 生产预览深链接、真实运行入口 |

只建立本组所需的最小测试条件。组件可用专用挂载页，不等整个后台，也不为验证引入大型展示系统。原/新装配不同，断言比较共同语义；截图仅证明对应视觉状态。

本组通过与页面集成分开。本组依赖和契约证据齐备即可使用，尚未迁页面的检查进入 `integration_checks`。没有检查条件的事项不能默认通过。

运行观测和源码推断冲突时调查，不能用新实现的结果定义正确答案。旧缺陷与用户允许的改善分别记录。密码、Token、完整认证 trace 不进入版本管理证据；只存脱敏字段、状态码和必要观察。
