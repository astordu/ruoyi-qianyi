# 确认迁移范围

读取本项目的 [grilling](../grilling/SKILL.md)，用它进行范围访谈。

明确 Vue 到 React 的迁移边界与输出要求。沿用用户已指定的源目录和目标目录；缺失时查明或询问，不预设项目路径。Vue 版本、组件库等事实从代码中识别。

重点查清：

- 入口及纳入的列表、详情、弹窗、授权、导入导出和关联跳转。
- 明确排除的功能，需保留的操作/权限/视觉，以及允许改变之处。
- 与其他模块、公共布局、菜单、请求处理的依赖；运行原版需要的账号与数据。

先探索真实 Vue 页面及相关依赖，再给人可核对的范围清单。区分代码中存在的功能和运行环境实际启用的功能；没有运行条件时注明未知。调查只沿当前模块展开，不要求全项目逐文件阅读。
