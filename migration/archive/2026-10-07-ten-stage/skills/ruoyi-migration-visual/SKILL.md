# 比较同条件截图

读 [共享协议](../../../migration/CONTRACT.md)、已确认需求的 visual_states、baseline 环境/旧图、目标清单与行为报告。源/目标指纹或原版基线无效时先更新相关阶段。

1. 复用同浏览器、viewport、语言/字体/时区、账号权限和确定数据；列表排序、分页、滚动、展开/弹窗状态保持相同。记录数据复位及两边共用的动态区域遮罩。
2. 用可用浏览器工具真实运行 React 并捕获每个要求状态。检查旧版与目标图；需要时生成差异图或并排图。没有运行/截图工具就记录 blocked，不用画图、旧图复制或主观描述代替真实目标截图。
3. 区分环境噪声和布局/字号/控件/交互状态问题；逐场景写具体差异及影响。容差来自当前视觉要求，不套一个任意相似度阈值来宣称全通过。
4. 图片对比不证明 API、按钮、权限或副作用正确，行为验证仍是独立门槛。截图中的空数据或失败状态不能自动当目标正常页通过。
5. 写 visual.json，包含场景/状态、原图与新图/差异图、环境、实际观察、状态及版本绑定。baseline 未覆盖的要求状态先补旧版证据。

可修复差异返回 implementation；设计差异交人对具体截图决定，复用已明确允许的差异。禁止自动更新原版基线或擅自记人工接受。保存 state/handoff，行为和视觉均通过后才 ready_for_acceptance。
